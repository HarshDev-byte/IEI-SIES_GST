# Junior Council Portraits Directory (/assets/jc/)

Copy and paste your Junior Council member image files directly into this directory (`public/assets/jc/`).

### Supported Naming Conventions:
You can name image files using any of the following:
1. **PRN / ID** (Recommended): e.g., `124A7003.jpg`, `124A1118.png`
2. **Slug**: e.g., `prathamesh-bhagwat.jpg`, `indrayani-patil.jpg`
3. **Clean Name**: e.g., `prathamesh.jpg`, `indrayani.jpg`

### Supported Formats:
- `.jpg` / `.jpeg`
- `.png`
- `.webp`
