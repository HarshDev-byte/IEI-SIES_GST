# Senior Council Portraits Directory (/assets/sc/)

Copy and paste your Senior Council member image files directly into this directory (`public/assets/sc/`).

### Supported Naming Conventions:
You can name image files using any of the following:
1. **PRN / ID** (Recommended): e.g., `123A7018.jpg`, `123A8043.png`
2. **Slug**: e.g., `tejraj-gujar.jpg`, `sarang-patil.jpg`
3. **Clean Name**: e.g., `tejraj.jpg`, `sarang.jpg`

### Supported Formats:
- `.jpg` / `.jpeg`
- `.png`
- `.webp`
