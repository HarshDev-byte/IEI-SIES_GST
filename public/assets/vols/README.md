# Volunteers & Coordinators Portraits Directory (/assets/vols/)

Copy and paste your Coordinator and Volunteer member image files directly into this directory (`public/assets/vols/`).

### Supported Naming Conventions:
You can name image files using any of the following:
1. **PRN / ID** (Recommended): e.g., `125A7059.jpg`, `125A7046.png`
2. **Slug**: e.g., `krishna-tiwari.jpg`, `riya-prajapati.jpg`
3. **Clean Name**: e.g., `krishna.jpg`, `riya.jpg`

### Supported Formats:
- `.jpg` / `.jpeg`
- `.png`
- `.webp`

The chapter portal automatically discovers and displays these images for Technical, Industry Outreach, Design, Creative, Media, and Editorial domain wings!
